# Wonders Landing Page

Проект адаптивной стартовой страницы, созданный с использованием чистого HTML, CSS и JavaScript.

Технологии:
HTML5 - разметка.
CSS3 - современное оформление с пользовательскими свойствами.
JavaScript (ES6+) - чистый JavaScript для интерактивности.

Особенности:
Адаптивный дизайн.
Поддержка модульности CSS: один файл на компонент/секцию.
Проект использует подход "mobile-first".
