# Wonders Landing Page

A responsive landing page project built with pure HTML, CSS, and JavaScript following mobile-first principles and BEM methodology.

## 🚀 Features

- **Mobile-First Design** - Optimized for mobile devices with responsive breakpoints
- **Pure Vanilla Stack** - No frameworks, no build tools, no dependencies
- **BEM Methodology** - Clean and maintainable CSS class naming convention
- **Modular CSS Architecture** - Organized styles using SCSS-like structure

## 🎨 CSS Architecture

### Core Files:
- **`_base.css`** - Base styles, box-sizing, body defaults, typography
- **`_normalize.css`** - Cross-browser consistency and CSS reset
- **`_font-face.css`** - Web font declarations and loading
- **`_vars.css`** - CSS custom properties (colors, spacing, breakpoints)
- **`_site-layout.css`** - Container, grid system, layout utilities

## 🛠️ Technologies

- **HTML5** - markup
- **CSS3** - Modern styling with custom properties
- **JavaScript (ES6+)** - Vanilla JavaScript for interactivity
- **BEM Methodology** - Block, Element, Modifier naming convention

## 📱 Responsive Design

The project follows a **mobile-first** approach with breakpoints for:
- Mobile: 360px - 768px (default)
- Tablet: 768px - 1000px
- Desktop: > 1000px

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required!


## 📝 Development Guidelines

- Follow BEM naming: `.block__element--modifier`
- Mobile-first CSS: write mobile styles first, then add media queries
- Use CSS custom properties from `_vars.css`
- Keep CSS modular: one file per component/section
- Optimize images: use appropriate formats and sizes
